Feel the Force

Following on from his Doom RPG port, BigChat88 has today released his AI-assisted port of Star Wars: Dark Forces to the Nintendo 64. This FPS was ahead of its time, bringing features such as jumping and crouching as well as the ability to look up and down vertically, features we take for granted today, yet most games lacked during that fledgling era of 3D video games.

Star Wars: Dark Forces was initially released on PC in 1995 and eventually made its way to the original PlayStation in 1996, but it never came to the Nintendo 64. Instead, we got Star Wars: Shadows of the Empire, a rather dull and awkward game that tells the tale of the period between Empire Strikes Back and Return of the Jedi in third-person perspective through Dash Rendar. I for one would have much preferred a game like Dark Forces with Kyle Katarn's first-person laser blasting alone, but the size of the game far exceeded that of an N64 cart.

BigChat88 has managed to compress this ~300 MB ISO into a mere 64 MB Z64, so if you want to have a pop at uncovering and stopping the Galactic Empire's secret Dark Trooper Project, follow the instructions below:

 

Dark Forces 64

A port of Star Wars: Dark Forces to the Nintendo 64, built on The Force Engine and libdragon (the open-source N64 homebrew SDK), plus a tool that turns your own copy of the game into a runnable .z64.

No copyrighted game data is in this repository. You supply your own Dark Forces files; the build packs them into the ROM.

What you need to play:

An Expansion Pak (4MB RAM upgrade), on real hardware or the equivalent option in your emulator. The game needs it and won't boot without one.

Saves go to the cartridge's SRAM (256 kbit): your flashcart or emulator handles that automatically.

On real hardware, a flashcart that takes 64MB ROMs (most do, e.g. the EverDrive-64 or the SummerCart64). The ROM is about 63MB: the level files are packed without their indentation and comments to make it fit (see tools/compact_levels.py); your own game files are not modified.

The game files you need:

A legally obtained copy of Dark Forces (the original CD, GOG or Steam release). From its install folder you need:

DARK.GOB, SOUNDS.GOB, SPRITES.GOB, TEXTURES.GOB

LOCAL.MSG

the LFD folder (*.LFD)

Copy them into gamedata/, keeping LFD/ as a subfolder. Letter case doesn't matter. You can also drop a single .zip of your install folder into gamedata/, or point the packer at the install folder directly with --gamedata.

Music:

Dark Forces' music is General MIDI. The project ships the SoundFont it plays it with, a Roland SC-55 style one (soundfont/SC55.sf2); every build converts it and packs it into the ROM, nothing to do on your side. See soundfont/README.md.

How to build the ROM

You only need Python 3 on your PATH (python --version). No Docker or N64 toolchain.

Grab the latest Release and unzip it.

Put your Dark Forces files in gamedata/ (see above).

Build it:

Windows: double-click build.cmd (or run it from a terminal).

Any platform: python tools/pack_rom.py

Wait for OK -> output/darkforces64.z64. That file is your ROM: run it in an emulator (e.g. Ares, simple64) with the Expansion Pak enabled, or copy it to a flashcart (e.g. EverDrive-64).

Other sources for the game files:

python tools/pack_rom.py --gamedata "C:/Games/Dark Forces/Game"

python tools/pack_rom.py --gamedata path/to/dark-forces.zip

The Release ships the host tools for Windows and Linux x86-64. On other platforms, build them with tools/vendor/bin/build-tools.sh (see tools/vendor/bin/README.md).

While no files are provided with the binaries, it is relatively simple to build if you own your own copy of the game on GOG or Steam. There are alternate methods to obtaining said files, but that's entirely up to you. Locating a reasonably priced physical copy of this game to rip and dissect, purely for the purposes of playing it on the N64, might also be quite challenging or expensive these days.
