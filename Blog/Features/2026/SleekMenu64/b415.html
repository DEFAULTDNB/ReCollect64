Today I have learned that another N64 menu is in development for our Nintendo 64 flashcarts. This time the author CathodeJay, with the assistance of AI, has made an N64 ROM that runs alongside any other menu and loads ROMs with box art and metadata, has three views, cheats, and a handy category filter system.

In order to fully set this game browser up, you will need to use Python 3.9 (or higher) and Pillow, as well as the N64-Flashcart-Menu-Metadata file to build your library. Follow the instructions below for more details:

 

SleekMenu 64

A game browser for the EverDrive-64. It is an ordinary N64 ROM that you start from the EverDrive's own menu: it shows your library with box art, genres, descriptions and filters, and boots the game you pick. The EverDrive's menu stays where it is — SleekMenu sits beside it on the card, and a reset or a power cycle brings the stock menu back.

Works on the EverDrive-64 X7 and the EverDrive-64 Pro with one and the same ROM. Saves go to the same ED64/gamedata/ folder the stock menu uses, so a game started from either menu carries its save into the other.

What you need

An EverDrive-64 X7 (OS 3.11) or an EverDrive-64 Pro, with your ROMs in a ROMS folder on the card, in any sub-folders you like.

A computer with Python 3.9 or newer and Pillow (pip install Pillow) to prepare the card. No compiler, no toolchain.

Install

1. Get the two release files from this project's releases page:

SleekMenu64.z64 — the browser

sleekmenu-prep.pyz — the tool that builds the catalog and the covers

2. Get the box art and descriptions. Download release-metadata.zip from the n64-flashcart-menu-metadata releases. It is a public-domain collection of box scans and descriptions for every cartridge, shared with other N64 menus. SleekMenu ships none of it and never downloads anything itself.

3. Copy the three files to the root of the card, next to ROMS:

/SleekMenu64.z64

/sleekmenu-prep.pyz

/release-metadata.zip

/ROMS/...

4. Run the tool from the card. It takes no arguments; running it from the card is how it knows where the card is.

cd /Volumes/CARD # or wherever the card is mounted

python3 sleekmenu-prep.pyz

It reads every ROM, matches each one to its box and description, and writes sleekmenu/catalog.ebc and sleekmenu/covers.pak beside itself. A card of three thousand games takes under a minute. Run it again whenever you add games.

5. Eject the card, put it in the cart, and start SleekMenu64.z64 from the EverDrive menu. Press A on a game for its details, Start to play. To get back to the EverDrive menu, reset the console.

What the tool writes, and what it leaves alone:

/sleekmenu/catalog.ebc titles, genre, publisher, year, descriptions

/sleekmenu/covers.pak every cover in one file

/sleekmenu/favorites.txt written by the browser as you star games

/sleekmenu/history.txt the last fifteen games you launched

/sleekmenu/cheats.txt which cheats are on, per game

/ED64/gamedata/ saves, shared with the EverDrive menu — never touched

Both the catalog and the covers are optional: with no catalog the browser scans the card and shows filenames, with no covers it draws a placeholder. The tool never moves, renames or deletes anything on the card.

Intuitive After Install

Controlling the menu is simple. The A button opens a folder or shows a game's details; the B button goes back; the C-left/C-right buttons select tabs; C-up changes views (list, cover flow or grid); the shoulder buttons jump to the previous/next letter; the Start button starts a game, and the trigger shows details and allows filtering. All the rest of the navigation is controller by the D-pad or the analogue stick.

The main feature here is that this menu is compatible with all major flashcarts, can handle libraries of over 3,400 games, and though the set up is a little finnicky (essentially install Python and run the PYZ file), it is entirely optional. You could just whack this on an existing EverDrive or SummerCart set up, run the SleekMenu 64 ROM and enjoy browsing from there, but I would advise the use of the meta data pack for best results. Setting this ROM to auto boot on start up also gives the feeling of a complete menu replacement if you're brave enough, but regardless, everything is easily reversable and will not mess with existing installations.

UPDATE: 21/09/2026 - V1.1 has been released with the following updates and fixes:

Games are found anywhere on the card, not only in ROMS/ (or pick one folder in the GUI and sleekmenu64 will remember it)

- Hacks that black-screened should now boot: the header checksum is fixed at launch, like the EverDrive menu does

- Games with special characters in their name (Pokémon…) showed up twice with weird characters and wouldn't start if the card was prepared on a Mac

- Long descriptions now scroll instead of being cut off (you can also use the d-pad to scroll manually)

- X7: games that use the clock (Animal Forest) get it set at launch. Thanks TheDiscordian for the PR!

New: a prep app

Preparing the card used to mean running a Python script in a terminal. Now there's an app for Mac (Apple silicon and Intel), Windows and Linux, nothing to install:

- Pick your card, press Download (box art, first time only), then Prepare

- The Catalog tab shows your card the way the console will: every game with its box, genre, year, publisher…

- Search your library, and change any game's title, genre, publisher, year, players, region, description or box art. Save puts it on the card right away

- Added games? Prepare again. It only reads what changed, so it takes seconds It's not signed, so macOS and Windows will warn you the first time. The README says what to click.

* Note that the app is unsigned so it will raise a warning on Mac and Windows.

Other new features

- Start launches the game straight from the list, A still opens the details

- Box view: A on the details shows the box art full screen, with optional high-res boxes (must be downloaded using the GUI prep tool)

- Games you copied since the last prepare show up anyway and play (marked NOT IN CATALOG)

- Your own box art and metadata, handy for hacks and homebrew

- Version number on the start screen
