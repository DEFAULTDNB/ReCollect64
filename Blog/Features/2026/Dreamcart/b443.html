Dreamcart N64 Cart Reader

Play N64 Carts on Your DC! ~ Nov 16, 2026

Plug-and-Pray

ThroatyMumbo, a name synonymous with modding and hacking consoles, has now come up with something truly unique. With the idea in mind that it would be "odd and quirky" to hook up an N64 cart to a Sega Dreamcast, he set to disassembling an N64 to obtain the cart reading socket, building an interface for the Dreamcast to read the ROM and save data from the cartridge directly using a RP2350B-based MCU connected to the DC's controller port, and then utilise that data to play the game sufficiently though this is where the biggest issues exist.

With ROM reading working, he looked towards 3 approaches for making games playable. Based on Simpson474's fork of StrmnNrmn's Daedalus N64 emulator, he found that N64 emulation on the DC was extremely limited, with games running with glitches and exceptionally slowly. With native ports, there are just a handful currently available (most by Jnmartin84), but you could potentially use the cartridge to obtain the ROM's assets then run the respective game with ease. With a recompilation method, you could dynamically recompile the ROM and any patches thereof prior to runtime and reap the benefits, should it work.

Ultimately, using a combination of emulation and dynamic recompilation, ThroatyMumbo managed to achieve the best results, running games that aren't supported by the latest builds of the emulator and games that haven't yet been recompiled for Dreamcast already (such as Kirby 64: The Crystal Shards), albeit with graphical and audio issues as well as massive slowdowns in games such as Cruis'n World. Notably, Donkey Kong 64 would not boot up, because Expansion Pak support doesn't exist for this project yet either.

Each game demonstrated requires individual video fixes (Fast 3D, F3DEX/F3DLX, FEDEX2 or S2DEX2) as well as audio fixes (ABI1, nead or naudio), in what he described as an untenable whack-a-mole approach, essentially putting out fires to fix games individually. It's a shame that the results, while still impressive, aren't miraculous. It would have been incredible to see more games made available on the Dreamcast via this approach, even if the hardware element of it is extremely specialist right now.

As well as the hardware, there is a swanky BIOS menu for starting or swapping games (via in-game reset menu combo), and a VMU (66 blocks/32 KB) can even be used to save games that require a memory pak too. Though N64 is the main candidate for this video, ThroatyMumbo also showed off the fact that this technique could be used for SNES or even MegaDrive (providing you obtain physical cart sockets for these consoles). Regardless, it's a seriously cool project that might yet see improvements down the line.

His GitHub has already seen notable updates since the release of this video, which indicates support is being added for several more N64 titles, including Elmo's Number Journey, Tony Hawks Pro Skater 2 and Cruis'n USA and preliminary support for Pokemon Stadium 2 is also being worked on.
