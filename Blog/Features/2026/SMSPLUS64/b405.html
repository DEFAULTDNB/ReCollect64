SMSPlus64 Emulator Released

Emulator Elective

A Sega Master System and Game Gear emulator based on SMSPlus has been spotted this week, made in Libdragon by Fhoedemakers and assisted by Claude AI, though it initially released in May. The current release is now compatible with the Analogue 3D FPGA console and OG hardware but has similar issues to the unfixed version of Sodium 64 when run on the ModRetro M64.

Working on the SummerCart64 and EverDrive-64 X series and below, the emulator is being made with the target of running on all flashcarts, even with the latest flashcarts such as the EverDrive-64 Pro; however, it is currently incompatible with the Pro, which I also verified through testing.

I also couldn't get it to work as the default SummerCart64 emulator for SMS and GG ROMs, though running it stand alone worked perfectly. The speed of the emulator is excellent too, with very few, if any, frame drops noticed and a smooth overall experience across a range of retro ROMs, regardless of whether they were for Master System or Game Gear.

If you would like to give it a shot, just follow the link below and run it as a standalone z64 in the "smsPlus64" folder on the root of your SD card for best results (including configuration saving). In-game, you can press Z + C-right to open up the settings screens to make adjustments, or press Z + Start to return to the ROM loading dialogue.
