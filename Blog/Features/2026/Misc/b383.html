EverDrive 64 Pro Released

A New Flash Cart Appears! ~ Aug 1, 2026

For Professional Players

Believe it or not, the EverDrive 64 X7 series flash cartridge was released by Krikzz for the Nintendo 64 back in 2019. Now, some 7 years later, the EverDrive 64 Pro, the official successor to the X Series devices, has been announced and is shipping in a variety of vibrant colours, as we speak.

This version ushers in features such as native 64DD support (automatic combo launching for F-Zero X Expansion Pak), IPS/APS patching, a built-in TPak/CPak manager (featuring GB/GBC ROM dumping), new EFU firmware updates, box art display, and a button for disk swapping and activating cheats (cheats require the Expansion Pak). There are also a lot of technical upgrades going on under the hood, with a Cyclone 10 15.4k Les chip, 128 MB SDRAM, a 20 MB/s USB-C socket, and battery voltage monitoring to tell you when to replace the RTC-keeping battery.

 

ED64 Pro Features:

• Cyclone 10 FPGA

• 128 MB SDRAM (1024 Mbit)

• High-quality 6-layer PCB with hard-gold surface finish

• Native 64DD support

• RTC

• Support for all Game Pak save types (SRAM, EEPROM, FlashRAM)

• Cheat code support

• Controller Pak manager

• Transfer Pak manager

• IPS/APS auto patching

• Custom menu themes

• ROM metadata support

• Battery voltage monitoring

• Built-in FPGA-based NES core

• External emulators support

• On-board button for 64DD disk swapping and cheats

• High-speed USB port for development

Cart of Choice?

In addition to these features, the ED64 Pro is capable of a lot more besides. When it comes to cheat support, the additional memory now allows for 480 codes as opposed to the X7's 34; there is a menu themeing tool and also a Meta Data Tool for optimising and sorting images for the new and improved OS to use.

Krikzz has also released the ED64 Pro development resources on his GitHub site, with the aim of providing examples, tools and code that will allow developers to target the ED64 Pro hardware for their projects. This could mean clever developer tools for homebrew creation, or possibly interesting payloads or plugins for the existing OS, should it become open-source. We will have to wait and see.

The ED64 Pro costs £169 and will no doubt face stiff competition from the increasingly popular and cost-conscious open-source SummerCart64, which can be built by yourself for as little as £45 or purchased prebuilt for around £90. We have to remember that the ED64 Pro is newer and packs a Cyclone 10 FPGA, whereas the SummerCart64 (2024) opted for the Lattice ECP5 FPGA. I would love to get my hands on the ED64 Pro to give it a thorough shootout against the formidable SummerCart64 and my trusty daily driver, the ED64 X7.
