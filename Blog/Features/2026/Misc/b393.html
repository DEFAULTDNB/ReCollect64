Strategic Conquering

Today, the founder, CEO and creative director of Slipgate Ironworks, Frederik Schreiber, announced that he was not only decompiling the N64 version of Command and Conquer but also single-handedly porting the game to PC. This is not just any PC port; this one targets Windows 98 specifically, with the core compatibility built for 3dfx Glide/OpenGL exclusively.

The port titled Command & Conquer 3D will harvest unique assets from the N64 version combined with the FMV, soundtrack, UI and other elements from the PC version in an amalgamation that will encompass 3D terrain/buildings/vehicles and exclusive missions, with all the pizazz of the cut-scenes that were unceremoniously torn out from the original 64-bit iteration.

The Looking Glass

Originally made by Looking Glass Studios and released in 1999, the game itself was based on the 1995 PC title but, any N64-specific content was never released on any other platform. Frederik has already ripped and decoded terrain maps by using utilising various format compression/decompression codecs and has gotten a workable prototype running that contains N64-accurate tile maps, triggers, and waypoints and more.

For those who don't know, Frederik Schreiber heads the Aalborg, Denmark-based company Slipgate Ironworks, which has recently released Tempest Rising, a modern RTS that gives a massive reminiscent nod to the original C&C games. I would say that this port should be in relatively good hands!
