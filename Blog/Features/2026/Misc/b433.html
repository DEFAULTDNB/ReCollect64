N64 Cart FW Updates

The Peaceful Outcome and Sachz's (PDAXROM's) N64 Cart Flashcart is a fantastically inexpensive way to enjoy backups on your 64-bit console, so this page catalogues updates, changelogs, additional tools and features all in one handy place.

Installation: Upload the required firmware (depending on the cartridge hardware version, NTSC/PAL console) to your cartridge. Using the USB utility, upload the ROM manager for your cartridge. Attention! The name of the uploaded ROM manager must be n64cart-manager.z64, otherwise the cartridge will not start on the console.

Note: This device has 128 MB of storage (6-18 games). ROMs must be in .Z64 format and relative to the region the N64 Cart firmware has been flashed to as well as the region of the console you are using it on. After saving, you must press the console's [RESET] button to write save data to the cartridge. You can use the U64AAP tools to remove anti-aliasing (de-blur) from your ROMs prior to adding them to the device.

V1.13 [07/06/2026]

+ Add Qt-based ROMFS Manager GUI for browsing, uploading, downloading, deleting, renaming, and creating folders over USB or remote proxy.

+ Add ROMFS Manager build/deploy support for macOS, Linux, and Windows, with vcpkg/libusb integration and portable deployment helpers.

+ Add ROMFS Manager localization: English, Russian, Armenian, Persian, German, Spanish, and Brazilian Portuguese.

+ Fix ROMFS Manager transport and file-transfer error handling.

+ Fix FlashRAM emulation mapping.

+ Improve rom manager menu file operations and save handling.

V1.12 [17/11/2025]

+ Added support for pseudo-directories in romfs

+ Commands for working with directories have been added to the cartridge utility

+ Game save files are now saved in the saves directory

+ A bridge for newlib has been added to romfs, which allows using the standard API to work with files (fopen, fread, fwrite, etc)

V1.11 [05/07/2025]

+ Support flash chips up to 128 MB

+ One user controllable LED, accessible from N64 side, RGB WS2812 for PCB version 3

+ UART port, accessible from N64 side

+ USB passthrough to N64 side

+ Emulation for EEPROM 4/16Kbit

+ Emulation for SRAM 256Kbit/1MBit

+ Emulation for Flash RAM 1Mbit (29L1100)

+ Support for emulators

+ USB utility to access to the cartridge flash chip as filesystem

+ Proxy and client for remote access to the cartridge
