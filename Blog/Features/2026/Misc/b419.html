PhosphorOS for SC64 WIP

Burning Brightly

Yet another OS has emerged for the SummerCart64, this time it's the stunningly emissive PhosphorOS by Kev "ForkyMcForkFace", which is a fully portable UI written in C, based on rgb-pi OS4. Notable features include box art and screenshot image display, in-game reset and console shut-down via the controller, animated themes and various screen adjustments geared for CRT devices. Check them all out in action, here:

 

PhosphorOS Features:

Progressive 240p by default, can be run at 480i if needed.

Menus can run in NTSC, PAL, PAL60, MPAL

Runs on PC, Pi, Steamdeck, Nvidia Shield, N64 SC64 (still working on Wii, Mister and any other device that has native CRT support or drivers capable of producing proper hdmi timings for CRT support)

Highly customizable theme support that works across all devices using the easy to use theme builder

Fully built out metadata for N64 and all emulated systems including retail, menu, and ingame images

Easily build and share collections without sharing actual rom files

Runs on N64 with 4MB memory

Boots in less than 500ms

Background music playlists

60fps menus and backgrounds

60fps visualizations for screensavers or backgrounds with Audio pump reactions

In-game-reset working on 80%+ of games (also works with all emulators)

Cheat support using standard libretro cheat files

Uses, but not limited to libretro rom folder naming convention

IPS, APS, UPS, BPS, VCDIFF/xdelta patching support

RTC, CPak, DD64, Cheats

No fixed ROM-count limit

No changes to libdragon

GPL3 (repo will become public after I finalize the Pi build)

Though the project has been in development for around a year, a public build has not yet been released, so please check back here soon for further updates!
