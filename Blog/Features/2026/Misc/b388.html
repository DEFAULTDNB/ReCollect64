Engine 64 Released

Tooled Up

A brand new game engine for the N64 has been released courtesy of Zoncabe. Engine 64 is a Libdragon- and Tiny3D-powered toolset, which began life following the 2022 N64Brew Game Jam and packs in a massive amount of features that gives anyone with a creative inkling for N64 homebrew a brilliant suite to work with.

 

Engine 64

Framework type game engine. Written in C on top of the open source SDK Libdragon and the 3D ucode & library Tiny3D.

Features

Physics engine

• A port of qu3e by Randy Gaul, expanded to use all basic primitives plus triangle meshes. Rigid bodies with island solving and sleeping, sequential impulse contact solver with warm starting, friction and restitution.

• Cloth simulation implemented using the Advanced Character Physics papers, a Verlet method developed by Thomas Jakobsen at IO Interactive for the Hitman games.

Character physics

• Collide and slide based character collision, resolved against boxes, spheres, capsules and triangle meshes. Floor detection and snapping.

Character movement

• Gait based movement system: target speed, acceleration and rotation response per gait, with exponential velocity convergence. Per asset settings for charged jump, air control and roll phases.

Character animation

• Blend tree based animation system: poses are sampled from clips and combined by weighted bone blending. Supports clip playback, selection, sequencing, 1D and 2D blend spaces and layering.

Screen system

• 2D screen system with a track based animation engine. Handles rectangles, sprites and text grouped in scissor sections, with easing curves, timed visibility windows and state driven lookups.

Scenes

• Scene definitions hold the level content: entities with model, transform and collider shapes, characters, and the physics world.

Camera

• Camera system with a spherical third person camera implemented, and the structure in place to add new camera types.

Building

• Install the Libdragon toolchain following their installation guide.

• Build and install Tiny3D.

• From the project root run "make"

Boundless Possibilities

With advanced tools like this that facilitate simplified homebrew building, the possibilities are, quite literally, endless. You could take this engine and quite easily build a sandbox open-world adventure game, or dial it back and animate your own cartoons or action sequences. The only limit is your imagination.

Zoncabe hopes that through donations, he can expand the features and make the project grow. Please take the time to check out his Itch.io page, and if you wish to use his tools, then please consider donating to ensure it remains alive and kicking.
