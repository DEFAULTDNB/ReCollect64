One Recomp is Never Enough

GoldenEye 007 is not the only N64 Bond game in town to begin receiving the recompilation treatment this week, as 007 The World is Not Enough is the next game in the series being thrust into the limelight thanks to the efforts of Modern Vintage Gamer.

Not much is known about the port yet, other than the few details listed below, but by using the N64:Recompiled toolset, MVG's recomp should bring us all the expected features hand-crafted, and ready to play as soon as the planned QOL upgrades have been included and a reasonable level of stability has been achieved. Here's a super secret sneak peak:

 

A sneak preview of my new side project - 007 The World is Not Enough - TWINE Recompiled, A static recompilation of the N64 game to PC with all the features you come to expect from a modern recomp project. 4k, 60+fps, wide screen, mouse/keyboard, mod support etc.

For more details about the main tool that was used to make this project, check out https://github.com/N64Recomp/N64Recomp

Release is coming soon... (no ETA yet)
