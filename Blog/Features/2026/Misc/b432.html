EverDrive 64 Pro FW Updates

The EverDrive-64 Pro is an absolute beast of a flashcart, and as such I want to keep all the update informatin in one place as well as changes and features that get added to the devices capabilities.

With the latest release (v26.1012) comes save states and an in-game menu which can be accessed by pressing [DOWN] + [START] by default and requires an expansion pak inserted in order to function.

Incidentally, the cartridge ID is now permanently set to "ED640027" when modifying the label art and details when using on an Analogue 3D. Note; the use of save states via flashcart is for use on OG hardware and are not recommended on the A3D, use the FPGA's built in memories function instead.
