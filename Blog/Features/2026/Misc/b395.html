Random-Eye-zer Released

Decompilation Adaptation

Thanks to the marvels of the on-going GoldenEye 007 decompilation project, which currently sits at around 98.7% complete, Murk-17 has put together the first public release of Random-Eye-zer, which randomises multiple aspects of the game, so that no run is ever the same!

Injecting longevity into the 29-year-old shooter, is done by leveraging decompiled instructions, modifying them and injecting them back into the ROM. Things like

 

Random-Eye-zer V1.1 Features

• Random level order

• Random guard models

• Random weapons

• Random music

• Random skyboxes

• Extra toggle options

(Demonstrated by AdzyIn3D last week, this mod is spectacular for replaying the game over and over again!)

Patch 'n' Play

All you need to use this mod, is to download the Xdelta patch from the link below, and point it at the GoldenEye (U) ROM using a patcher such as Marc Robledo's. The resulting file will have an MD5 of 7EBD5BD7EAADF91D1D4E8D03CEB18417, if you've done it correctly.

I gave this a brief test earlier and I have to admit, the potential this holds is almost unlimited, it's REALLY impressive how much milage this will add to replaying the game! I even enjoyed the fact that the opening screen has been altered to say that if you paid for this mod you have been scammed, and not to support the practice of buying bootleg carts with free software on them!
