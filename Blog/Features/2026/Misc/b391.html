NFM Grid & Themes WIP

Off Grid

As anyone who has ever used the SummerCart64 knows, the N64FlashcartMenu (NFM) is a stunningly fast piece of open-source software that rightly prioritises reliable utility over bells & whistles. That said, the OS looks pretty decent, but it has always been missing that slight pop to elevate it into something more than just a basic, clean interface.

Enter Scaevolus (Ryan Hitchman), a modder who wants to re-point the interface, giving it Windows-like paned panels, hued tints, backgrounds, and ultimately a nicer grid layout for box art. Take a look at the video below:

 

Description

Adds a unified settings tab at the top right, consolidating multiple separate screens into a simple paned interface. The new interface supports direct d-pad adjustment, a confirmation warning dialog for PAL60, and consistent action-bar hints.

This also standardizes L/R for switching tabs, allowing individual tabs to use D-pad freely-- useful for the settings pane and other tabs that might want to have left/right too.

It also cleans up a few strings ("Load" to show a ROM's info screen, "Launch" to execute it) that were inconsistent before.

Motivation and Context

Settings and system functionality was previous scattered around with inconsistent navigation patterns. This unifies it nicely. It's also a prerequisite to my Theme work, which relies on having a nice Settings tab with panes to do its configuration.

How Has This Been Tested?

Make all works, and all ROM variants build. I have tested the UI extensively in Ares, but have not confirmed this on hardware yet. (Because I'm still waiting for packages to arrive, will be able to do hardware testing in a week).

Pull Request

These changes are pretty nice, and if accepted into the main code stream, they will give the menu a slightly enhanced look, something more enjoyable to boot into, and something that doesn't detract from the original ethos of the project. The only element that might not initially make it is that of the background images. As a result, the author has opted for simpler gradient-colour backgrounds that can be drawn within the menu, rather than importing images to use as a wallpaper. Textures may come as an additional SD card theme extension later on.

For those wondering, the only dependency of this over the OG menu is that of the metadata pack being installed to organise cartridge images and game names. If the update does take root, be sure to check back here for updates and links!
