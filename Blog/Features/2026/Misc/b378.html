Byte-for-Byte Blasting

Following the news that Diddy Kong Racing is now 100% decompiled, SonicDcer has recently posted on Twitter regarding his decompilation of Star Fox 64, stating that it too is now in a state of 100% matching for the REV A version 1.1 NTSC-U ROM!

Starfox 64 Decompilation Project just reached 100% Matching for US 1.1 (REV A).https://t.co/S7ROFNoW0G

Special thanks to everybody who contributed to preserve this game!

— SonicDcer (@SonicDcer) July 29, 2026
 

Starfox 64 (US) REV 1.1

This is a complete matching decompilation of Starfox 64. The purpose of the project is to recreate a source code base for the game from scratch, using information found inside the game along with static and/or dynamic analysis.

Note: This is NOT a PC PORT.

It currently builds the following ROM:

starfox64.us.rev1.z64 MD5: 741a94eee093c4c8684e66b89f8685e8

This repo does not include any assets or assembly code necessary for compiling the ROM. A prior copy of the game is required to extract the required assets.

Note from SonicDcer:

The last 3 Equivalent Non-Matching functions, AudioSynth_HartleyTransform, Aquas_AqBacoon_Update and Titania_80193DF0 were matched thanks to a new tool made by a user who goes by the name of akratch, the same tool that helped DKR reach 100%, after getting the first match it motivated us to work on the rest and with the help of the tool we were able to match byte for byte all the remaining functions in the Starfox 64 Decompilation project.

Safeguarding the Lylat System

Crucially, the 1.1 REV A version of the ROM patched a bug whereby your high score, if over 511 on any individual level, would hit an overflow, and then incorrectly subtract 256 points from it. This cartridge revision can be identified by looking at the punch code on the rear label. There should be an "A" present after the two-digit date stamp which indicates that you own the patched 1.1 variant.

With this revision now perfectly preserved and publicly available, the game should survive the test of time, being able to be ported to multiple platforms in the future and in its absolute entirety, for generations to come. The enduring work of these digital preservationists should never go unnoticed. I tip my hat to SonicDcer and any of the contributors to this project; this is a truly amazing achievement.
