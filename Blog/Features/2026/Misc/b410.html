Vexxon N64 Port

Vectrex Game Ported to N64 ~ Sep 1, 2026

Nothing is Ever Black & White

In a move that was not on my 2026 bingo card, Rorodev, aka Roger Boesch, has released a fresh Nintendo 64 port of a Vectrex game he originally wrote for the 1982 console, using the more modern Raspberry Pi-based PiTrex hardware. The game is natively ported using the Libdragon SDK and uses a clever rendering layer that essentially converts the N64's pixels (triangles) into analogue vector beams (lines). It can be seen in action below:

 

An isometric vector arcade shooter that runs on a real Vectrex through PiTrex. Wireframe graphics, fuel-driven survival and true 3D altitude flight — a tribute to Zaxxon.

Vexxon was written for the Vectrex, a vector console from 1982. This is the same game code running on a Nintendo 64.

The Vectrex version runs bare metal through PiTrex. There is no operating system under it, and the picture is drawn as lines, one at a time, by an analog beam. For the N64, I left the game code alone and wrote a new rendering layer on top of libdragon, so both builds share the same source.

Captured in the ares emulator at 320x240. It sits at 40 to 50 fps right now, and I want a stable 60. The game has sound; I just cannot capture it yet, so this clip is silent.

I did not expect Vectrex games to be ported to the N64, as I had imagined that this console could emulate them well enough. In actual fact, there is no Vectrex emulator for the system at all, and porting this one might just open the gates for more of the 28 original classic games to land on our favourite 64-bit system.

Check the links below for the download and the write-up by Roger himself. Beware that the game currently only runs on Ares and is not ready for running on real hardware just yet. Check back here for more updates when it does become compatible!
