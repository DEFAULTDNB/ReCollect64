TROUBLESHOOTING TIPS


[WiFi Update]: Press Start + Z > About > Check for Updates. The M64 will reboot when complete.

[Wired Update]: Using a Chromium browser go HERE > Connect the M64 via the power socket > Press "Connect Device" > Select M64 and press "Connect" > Press "Update" ensuring the device DOES NOT say "Bootloader". The M64 will reboot when complete.

[SD Card Update]: Download THIS "M64.BIN" file > Copy to the root of your consoles SD card > Power on the console > Press Start + Z > About > Update from SD Card. The M64 will reboot when complete.

• If your console displays no picture or you think you have "bricked" your console, there is a recovery guide HERE.

• Firmware 1.23 is the first public version that released with the console on the 28th of July, 2026. The compatibility states 277 NTSC games are working with "no issues" and 16 games are still listed as "in progress".

• You cannot currently make or use save states or screenshots, or emulate memory paks on the console (or the Pro Controller).

• Overclocking can cause games to black screen or run too fast. Super runs +17%, Ultra runs +33%, Extreme runs +50%, and Insane runs +67% faster.

• Recommended settings for a clean image; select "Clean", under "experimental" in customisation; turn divot off, turn up sharpness, use integer+ fit, use "Lanczos-Integer" video scaling. Try overclocking for smoother frame rates.

• Recommended settings for a classic look; select native 4:3 and a CRT filter, adjust scanlines and gamma to suit. Try "Super"-"Extreme" overclocking to eliminate stutter or frame dips.

• With EverDrive 64 X5, in a game; you need to press Start + Z, navigate to settings, and press "Reset Core" to flush saves to SD card for saving.

• The Mr Backup Z64 accessory works with the M64. It does not work with the Analogue 3D.

• There is expected to an AUGUST 2026 firmware update to address game compatibility and more.
