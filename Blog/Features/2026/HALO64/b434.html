Halo Multiplayer on N64

Developed by DeadHamster ~ Oct 15, 2026

De-Master Chief

A couple of days ago, DeadHamster of Mario Kart 64 custom track creations and tooling fame shared a rather interesting homebrew project he has been working on over on the N64brew Discord. The project is a human-made facsimile of Halo: Combat Evolved's multiplayer that includes both a single-player versus bots mode and a full-on 4-player multiplayer experience.

Working on most emulators and original hardware thanks to demastered graphics built within a Libdragon-powered custom engine, this homebrew is quite incredible; however, due to the AI influx we are seeing in recent times, I fear that DeadHamster has indicated that the project might end up being shelved due to a recent artificially accelerated Halo: CE decomp port muscling this project into the sidelines.

 

There's a 4 Player and 1 Player vs Bots version in the ZIP.

Controls

A -- Jump

B -- Melee

R + A -- Swap Gun

R + B -- Reload

R + C-Up -- Zoom (Pistol)

Shields and Respawning should work. Plasma Rifle uses some rudimentary overheat system I hadn't gotten far with it. The plan was to eventually separate out the game's model data into a binary blob you would build with an external toolkit, so that I could ship the code opensource without copyright and upload the binary map files separately, which would also allow others to make their own maps/weapons completely unrelated to halo.

I had originally expected much more controversy around a Halo N64 Port when I began working on this years ago and planned on shadow dropping it when it was complete. That seems irrelevant now in the wake of this newfound AI revolution. I saw on Reddit today somebody had done a legitimate port that was miles ahead of this work 🤷

As impossibly quickly AI can churn out every port possible ever and clog up our timelines with bizarre mashups and expanded rosters, I would far rather follow the journey of legitimate developers attempting to build ports like these, so I sincerely hope that DeadHamster does continue on with Halo multiplayer for N64, because the ability to craft custom maps and weapons sounded wonderful!
