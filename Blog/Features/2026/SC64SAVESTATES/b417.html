UPDATED SummerCart64: Save States & More

Modded by John Steinmeyer ~ Sep 16, 2026
SummerCart64: Save States!

Saving Your States

The Nintendo 64 is not a modern console by any stretch, so the news that modern features such as save states have been made a reality on the console is nothing short of mind blowing.

By leveraging the added memory of an Expansion Pak, John Steinmeyer has managed to eke out save states, a virtual Controller Pak, suspend/resume and slow motion for the SummerCart64, by modifying the hugely successful open-source N64 Flashcart Menu.

 

This fork adds, for the SummerCart64:

+ Save states. Hold L + R + D-pad Up in a game to save, L + R + D-pad Down to load, L + R + Start for a slot panel with thumbnails; states persist on the SD card. Nothing stays resident in the console's memory, so games that use the whole Expansion Pak work too.

+ A virtual Controller Pak (memory pak). A game that uses one gets a pak that lives on the SD card, whether or not a real one is plugged in; on by default for the games known to use one.

+ Suspend and resume. Suspend a game to a slot from the panel and switch the console off; the next launch of that game picks up where you left it.

+ Slow motion and frame step, as a per-game option.

NOTE: It needs an Expansion Pak and works with 276 of the 298 games tested so far.

What you need:

+ A SummerCart64.

+ An Expansion Pak. The top 128 KiB of it is the working room the routine borrows during a save or a load (and gives back, byte for byte, before the game runs again), so states are not possible on a 4 MiB console.

+ ROMs up to 48 MiB. The states are kept in the cartridge memory above the ROM; the bigger the ROM, the fewer slots fit, and a 64 MiB ROM leaves no room at all (the option refuses to switch on for those, and such a game gets no virtual pak either).

+ Free space on the SD card: about 8 MiB per slot per game, allocated the first time a game boots with save states on (48 MiB for a game with six slots), and 32 KiB per game for its virtual pak.

How to use:

+ Select ROM, open options, choose save states and toggle enable.

I will be testing this in the coming days and will update this article with my findings!

UPDATE: 17/09/2026 - Having given this a full testing this morning here are my results:

OG N64 Hardware:

Everything works as directed! Save/load states and the save state menu interface are an absolute godsend and virtual controller pak emulation is an incredible feature too if you're short on real memory paks!

Analogue 3D:

Save/load states and the save state menu work perfectly but using virtual controller pak doesn't seem to register anything at all.

M64:

Neither save states nor virtual controller pak works, which is unfortunate because this could have seriously bridged the gap for virtual controller pak support that remains missing from the official firmware.
