Mirlo64 for Analogue Pocket

Developed by Tortugaveloz ~ Oct 11, 2026

Portable Power

Analogue's portable, the Analogue Pocket is a neat little multi-system device that is compatible with the Game Boy, Game Boy Color & Game Boy Advance game cartridges, as well as Game Gear, Neo Geo Pocket Color, TurboGrafx-16, Atari Lynx & more, (legitimately) via cartridge adaptors.

Until recently, running Nintendo 64 games on the system was entirely off limits. That was until today, when Tortugaveloz released Mirlo64, an N64 core made specifically to fit in the Analogue Pocket which intends to replicate the N64 architecture the best it can. This method does not use a cartridge adaptor, it effectively loads ROMs, but you never know, someone might build one in the future.

 

Installing on the Pocket

Download tortuga.Mirlo64_< version >.zip from the releases.

Unzip it onto the root of the Pocket's SD card, merging with the folders already there. It adds only Mirlo's own files:

+ Assets/mirlo/common/ n64rt.sys (the runtime) and n64savedb.txt; where Mirlo's games go

+ Cores/tortuga.Mirlo64/ the core: mirlo.rev (the bitstream), core.json, ...

+ Platforms/mirlo.json the platform, under Console

+ Platforms/_images/mirlo.bin its image

Put the games (games in .z64 format) in Assets/mirlo/common/.

On the Pocket: openFPGA → Console → Nintendo 64, then pick a game.

Saves (.sav) appear in Saves/mirlo/common/ when you quit a game. To update the core, unzip a newer release the same way; it replaces the files in Cores/tortuga.Mirlo64/.

Features:

It replicates as best as possible the N64 architecture with all its components (64-bit MIPS processor, RSP, RDP, etc.). This is not emulation.

+ PAL and NTSC games are supported.

+ All savefile formats are supported.

+ Controller Pak and Transfer Pak support (only on P1).

+ Expansion Pak is included.

Please note not all games are supported yet! Working through the N64 architecture is a tedious process. Hopefully compatibility will improve in future releases.

If you have an Analogue Dock, several additional features become available:

+ Up to 4p split-screen multiplayer.

+ Joysticks are supported.

+ Due to the Dock's firmware, several limitations exist, namely: Rumble is not supported, joystick support is available only for bluetooth-connected controllers, and there is no joystick support in the N64 NSO controller. Hopefully Analogue addresses some of these in the future.

Current known limitations:

+ Many games still will show issues and / or won’t load. If you encounter issues, raising them in the github would be very appreciated and it would help the project advance, thanks a lot!

+ ROM size limit is currently 48 MiB.

+ Resolution is restricted to 240p NTSC, 288p PAL.

Some technical details:

+ This project provides a MIPS at 93.75 MHz (stock CPU clock), with all 32-bit instructions and most 64-bit instructions. Some 64-bit instructions were intentionally left out (such as fp64, for instance) and are managed through a trap. These instructions are mostly unused by N64 games, and were left out to have room for other components.

+ The RSP and RDP are at 62.5 MHz. There are a few concessions here. The RSP runs 4-lane vectorisation instead of the stock 8-lane vectorisation, however this barely affects speed. Mipmapping is also left out in the core's current form. Whether these two can fit in future iterations of the core is to be seen. Notably, blending and AA are in.

+ Most of the N64 interface is there. That includes: RCP commands (VI, AI, PI, SI), the MI, etc.

+ The SDRAM transfers at 125 MT/s. That is 1/4 of the RDRAM peak 500 MT/s.

+ Some video output modes are still unsupported.

+ The TLB is partially implemented. Still exploring ways for it to not take up much space.

+ Current focus of the project is to widen game support, and understand game by game what is missing. As the project is almost saturating the Cyclone V FPGA, each decision matters.

Pocket Rocket

Following his efforts to understand Nintendo 64-based sources and even port Super Mario 64 to the Analogue Pocket, an N64 core seemed to be the next logical step for getting a wider range of games working on the handheld more quickly.

Analogue's inclusion of openFPGA with the Analogue Pocket is crucial to this working as this is not simply software emulation; it's hardware-level emulation. OpenFPGA is a developer platform and open-source hardware ecosystem, which essentially allows anyone with enough technical knowledge to craft operable cores in the system.

Sadly, some games such as GoldenEye 007, Donkey Kong 64, Mario Tennis and F-Zero X do not currently work with the current release, but staples such as Super Mario 64, Diddy Kong Racing and The Legend of Zelda: Ocarina of Time work well, even when docked and with up to four players where applicable!

Hopefully compatibility will improve as the core matures, but I will be keeping an eye on this as it progresses to share updates and more.
