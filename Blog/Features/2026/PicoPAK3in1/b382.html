PicoPAK 3-in-1 Released

Marvelous Multitool

Built from a simple Raspberry Pi Pico, Ocelo456 has been busy beavering away at a fresh new project, one to unify almost all N64 accessories into one slimline package. The PicoPak 3-in-1 aims to do away with the need to manually swap out peripherals, opting for one device with a switching button.

The hub board connects to the N64 controller's accessory expansion port, and the Pi Pico is soldered to it along with a switch for operation and, of course, a slim-line vibration motor on the rear. The memory pak function has four save slots and is safe for around 700,000 writes, the vibration mode has 3 levels of intensity, and the transfer pak feature is compatible with a variety of games such as Pokemon Stadium, Mario Golf, Mario Tennis, Power Pro, and Robopon; all you need to do is upload your .GB/.GBC ROM and .sav files to the device.

Flashing the board over USB, the current .uf2 firmware, version 2.00, is as simple as plugging it into a PC and dragging the file onto it.

Previous Projects

Ocelo456's previous projects include "consolised" handhelds, built-in Bluetooth adaptors and much more besides, so you know that their productions are high-quality. My favourite one, prior to the PicoPAK was the miniaturised Rumble Pak, which is essentially a rumble pak within the tiny memory pak form factor, which also required no batteries to operate. If that had memory banks built in, it would have been essential, but for now the PicoPAK has far exceeded the mini rumble pak's features and stands out as an amazing idea that has been envisioned, built and sold.

If you would like to purchase either of these N64-based projects, please check out the links below, or follow Ocelo456 on Twitter/X. The 3-in-1 assembly kit currently sells for ¥3000; that's about £14 GBP or $19, and the pre-built device (with no shell) sells for ¥4000, which is around £19 GBP or $25. Not too expensive at all!
