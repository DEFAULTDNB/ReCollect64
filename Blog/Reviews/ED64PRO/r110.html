EverDrive-64 Pro

Flash Your Carts

It feels like only yesterday I purchased my EverDrive-64 X7, but it was in fact almost 5 years ago because I waited a while and ended up snapping up a tasty Black Friday deal. Nevertheless, the EverDrive-64 X7 (2019) is no longer the biggest, baddest, flashiest cartridge for the Nintendo 64 offered by Krikzz; that mantle goes to his brand-spanking new EverDrive-64 Pro.

Enhanced in almost every way, the Pro (2026) features upgraded FPGA architecture, more RAM, expansive feature-rich firmware, and, to top it off, a swanky new button to slap on the top!

 

Technical Specifications:

+ Cyclone 10 FPGA

+ 128 MB SDRAM (1024 Mbit)

+ High-quality 6-layer PCB with hard-gold surface finish

+ Native 64DD support

+ RTC support

+ Support for all Game Pak save types (SRAM, EEPROM, FlashRAM)

+ Cheat code support (requires Expansion Pak)

+ Controller Pak manager

+ Transfer Pak manager

+ IPS/APS auto patching

+ Custom menu themes

+ ROM metadata support

+ Battery voltage monitoring

+ Built-in FPGA-based NES core

+ External emulators support

+ On-board button for 64DD disk swapping and cheats

+ High-speed USB port for development

(I was very kindly sent the clear variant for review purposes)

Less Limitations

I began by loading up a 32 GB MicroSD card with the latest firmware update, ed64-pro-fw-v26.0812.efu at the time of writing. I inserted the ED64-Pro into my brand new M64, selected the EFU file, and clicked update. The process wass very easy, and in doing so, it also ensured that my SD card was prepared with a system folder and other bits I would need to configure things later on. There is no need for an OS to download first or a bootloader binary to flash; the EFU is an all-in-one that also includes the FPGA NES emulator.

Once set up, I took my SD card to my laptop and added the IPL files for 64DD loading, a selection of legally obtained ROMs, and some updated emulation files specifically for the M64, that should fix issues when loading GB/GBC and SFC ROMs on the newly released FPGA machine.

When it comes to N64 ROM loading, the ED64 Pro is, as the name suggests, a complete professional. Games run perfectly with minimal configuration, but should you need to, you can edit the ROM region; each ROM generates a save folder with the save (SRA/FLA/SRM/EEP) within it, any cheats you've applied, and an INI that stores your specific configurations. For ROM hacks or betas like Dinosaur Planet, for example, you can specify the save type rather than needing to hunt through and modify a singular save_db.txt. It feels cleaner and more usable this way.

On the OG N64 hardware, this flashcart is a beast, exhibiting no issues whatsoever. On FPGA hardware, it is limited to whatever performance the FPGA is outputting, so be wary if using this device, specifically on an M64, because performance is in parity with their already shaky game compatibility, which has actually increased the number of games that have issues since launch from 16 to 20. The Analogue 3D displays far fewer performance issues, and the horizontal upscaling makes the ED64 Pro menu look even more crisp.

It should be noted that larger ROM hacks that would not run on the original EverDrive 64 and ED64 X series carts *might* now work. The ED64 Pro packs 128 MB SDRAM, as opposed to the X series 64 MB, which means expanded Super Mario 64 ROM hacks such as B3313 Unabandoned, which is 96 MB, and larger-scale wrestling bundles like ECW: Born to be Wired, which is 72 MB, can at least now boot up, but they might need further patching by the authors to get them fully working outside of less-restrictive emulators. The scope for this is huge, and it means ROM hackers and modders can be all the more expansive with their console-compatible creations going forward!

Running out of memory for cheats is also a thing of the past here. The 128 MB memory allows for up to 480 individual cheat entries to be run and experimented with simultaneously, per game. This is an incredible increase compared to the originals' 34 code limit, which, let's be real, was plenty for us end users to play with already. This means that developers can experiment with a lot more at the same time, giving them a better grasp on what works, what doesn't and what combinations can be used to push games further with more complex cheats and mods. Regarding development, the USB-C connectivity is also upgraded, with a 20 MB/s Type-C socket compared to the X series' 1 MB/s transfer rate. This means that devs can now utilise loader64 or usb64 for radically faster ROM loading and debugging.

(Native 64DD loading is great, especially with the proto/modded IPL.)

Expansive Elements

Emulation-wise, all the ED64 Pro needs are folders named with the file extensions of the ROM you want to play (e.g., "gb"/"gbc"/"sfc"/"gg") and the relevant emulator *.v64 file within their individual folder, which in turn are placed within the "edapp" folder. When selecting a retro ROM, it will then run the game with the correct emulator automatically. Mileage varies with emulation on the N64, specifically when you get up to the 16-bit level of SNES games; however, through testing, I have discovered information that should be extremely useful to FPGA users as well as OG N64 owners.

Using the M64 "fixed" versions of GB/GBC/SNES is a must, but only for M64 owners. Using the vanilla versions causes the graphics to be glitched out when attempting to load retro games on ModRetro's machine. Running GB/GBC and even GG games usually works perfectly regardless of fixed files or not, but SNES ROMs are painfully finicky regardless of platform, and any overly technical games, such as anything that uses mode-7 scaling or required the Super-FX or SA-1 chip, will simply not run. For best compatibility, pre-convert any ROMs (preferably NTSC-U) to *.Z64, rather than running raw ROMs. OG N64 users and Analogue 3D owners should simply convert their SNES ROMs using the original Sodium64 conversion tool with the unpatched Sodium64 .z64 emulator ROM. M64 users should again use the modified emulator z64 ROM with the original N64 ROM converter tools. Be warned that on the M64 they still run slightly glitched and horribly slowly unless overclocked, but this is clearly an M64 specific issue.

I tested Donkey Kong Country and Super Mario All-Stars, and they ran perfectly this way on OG N64 and A3D. Unconverted SNES ROMs and M64 "fixed" converted SNES ROMs also ran badly on the A3D and OG hardware, so bear this in mind when it comes time to replay your childhood games. TLDR; M64 turned out to be the worst for SNES emulation, even with fixed or preconverted files.

In addition to the FPGA NES core already being present and working brilliantly across every game I threw at it, the ED64 Pro now also loads 64DD (*.NDD) files natively when paired with their sibling ROM. For example, when the F-Zero X USA translated Expansion Kit .NDD file is sat next to the F-Zero X USA ROM, as you load the N64 ROM, it also automatically loads the Expansion Kit add-on. On other flash carts, you need to highlight the base ROM, back out, find the NDD add-on, hold R and select "launch both". This is a far simpler implementation, which I feel comes from having studied its competitors and the EverDrive 64 lineage is now catching up with the likes of the SummerCart 64 (2024).

Last but by no means least, the Mpak and Tpak functionality has to be mentioned as being excellent. You can back up and restore memory cards, and even dump GB/GBC ROMs through a transfer pak (this can be done on SC64 too with THIS additional tool). For those wondering, you can also use SwapDumper (or the CRC modded version) to dump your N64 games to your flashcart's SD card too. The ED64 Pro is really a swiss army knife in terms of baked in features, compatibility and unwaiveringly stoic reliabilty.

(The onboard features are expansive and useful, no PC is required for a multitude of tinkering tasks.)

Cartridge Consumers

As we know, the SummerCart 64 already had USB-C, the metadata pack, native 64DD loading and larger ROM hack compatibility (78 MB), backed by open-source software, so how does Krikzz's latest 64-bit EverDrive compete?

The biggest thing Krikzz has is a consistent standard of quality when it comes to manufacturing, a heavily polished and responsive OS with robust functions and cheat support, and now even more expansive homebrew and ROM hack compatibility. The OS is sleek and intuitive; you can even theme it as you wish, and you can copy, paste, text-view, hex-view, and more with a refined UX as well as a crisp and streamlined GUI.

With over a decade of research and design behind it, and a guaranteed safe and high-quality component build that even optimises power draw of the N64 and displays your RTC battery level, Krikzz's products do come with a heftier price tag because of their almost luxury-brand-like status. Sure, you could buy a SummerCart for a fraction of the price, but because of the SC64's open-source nature, unless you're buying from a reputable source such as Phenom Mod, they will more than likely be extremely mass-produced low-quality effigies, use unstable cloned chips, and might not even feature the button for cheats/disk switching or a USB socket at all.

There is an argument for both, but it's nice to see some healthy competition in the N64 flashcart sector. With news that an upgraded SummerCart64 Pro variant is in the works too, it will be interesting to see just how that fares against the ED64 Pro when it does eventually release.

(Drop a firmware update and go. The ED64-Pro doesn't require any messing about to get you set up)

Other Oddities

Throughout my week of testing, I experienced a couple of odd things, which, while they aren't entirely game-breaking, are certainly odd nonetheless. Banjo-Tooie's USA ROM will only launch on the FPGA consoles with the MPAL region selected; no other region Tooie ROMs (A/E or J) wanted to work on any FPGA system, regardless of region switching. F-Zero-X would also not load either the USA-translated or JPN DD expansions on the M64 at all. The A3D would run the USA translated Expansion kit fine, but not the JPN original. It has to be noted that the OG N64 hardware has zero issues with any of these, so these are certainly FPGA-relative issues.

Some meta information was cut off or missing, even after converting the metadata pack for use on the ED64 Pro. Again, not a game breaking issue, but strange behaviour that possibly needs addressing in a future firmware update. I also noticed that portrait JPN covers in the untouched metadata pack are 112x158px (158 x 112px for landscape EU/USA covers), but the EDMETA tool converts them to 170x120px which makes them look squished when viewed in an image viewer; however, they look to be corrected when displayed on the ED64 Pro. Equally, any cartridge images are 158x112px in the untouched pack, but the EDMETA tool converts them to 240x85px, which is stretched in an image viewer, but they appear corrected when in use on the ED64 Pro. I'm sure Krikzz knows what he's doing, but it seems like an odd and potentially unnecessary process.

Tapping into the community metapack is a great concept on paper, but is it right for the ED64 Pro? I'm not sure. I had hoped for a bit more visual lustre from the ED64 Pro, but perhaps that will come in time. A lot of developers are currently working on new UIs and graphical experiences for flashcart ROM loading, so hopefully they will be able to adopt the ED64 Pro as a basis (like ALT64/ALTRA64 did), or maybe the N64FlashcartMenu will support the ED64 Pro going forward, because that is what most of these snazzy open-source menus are being built upon.

The Pros:

 Works brilliantly for N64 games on all consoles.
 Fast-loading and reliable for gaming and saving.
 Massive 128 MB SDRAM for bigger ROM hacks & up to 480 codes.
 Native 64DD loading uses the cleanest implementation yet.
 Button can be used to change disks or enable/disable cheats.
 Emulation up to SNES is excellent on OG and A3D consoles.
 Built-in hex/text editor, Mpak backup/restore & Tpak ROM dumping!
 High-speed USB-C socket for developers.
 Onboard battery voltage monitor is a handy feature.
 An awesome selection of colours are available.
The Cons:

 Metadata support isn't mind-blowing.
 Has teething issues on FPGA machines.
 £130 ($169 USD) is not cheap but you ensure high quality.
Conclusion:

The EverDrive-64 Pro is no doubt an absolute powerhouse, but sadly the average N64 pirate will not fully appreciate this for expansive ROM handling and developmental abilities.

Updated hardware aside, the experince feels slick and well rounded, and every feature works with lightning speeds efficiency and reliability from the word "go".

This is a no brainer of an upgrade from the X7 to the Pro, let alone anyone on the X5 or below (V3/V2.5 or clones). This has already become my new daily driver and feels like an essential flashcart that is justifiably 110% worth the pricetag in my opinion.
